# Week 1: Setting Up the Repository

*27 Jul – 2 Aug 2026*

## What I did

Created the project repository from the course template: the MkDocs documentation skeleton, the Makefile, `pyproject.toml`, the docs workflow, a sample C++ project under `code/` and the journal folder. Tagged the first release, `v0.0.1`, through a release branch.

## Problem

The template is generic: none of it describes our project yet, and its sample code is not ours.

## Fix

Kept the template's structure (docs, journals, reports, code) as the layout for everything to come, and treated the sample code as a placeholder to replace once we had a prototype.

## Learned

A release branch and a version number from day one cost nothing and make every later "what changed?" question easy to answer.
