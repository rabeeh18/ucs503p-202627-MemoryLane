# Voice Search

The MemoryLane web interface supports voice input for search queries.

A microphone control is available alongside the normal search field.

## Using voice search

1. Activate the microphone control.
2. Speak the query.
3. The recognized text is placed into the search field.
4. Submit the query normally.

Voice search is an alternative input method; the resulting text is processed through the same search interface as a typed query.
