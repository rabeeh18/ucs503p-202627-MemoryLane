# Voice Search

In browsers with speech recognition (Chrome and Edge), the search box shows a microphone button.

1. Press the microphone and allow microphone access if the browser asks.
2. Say your query.
3. The recognised text appears in the search box.
4. Press `Enter` to search.

Voice input only fills in the search box: the query then goes through the same search as a typed one. Speech recognition is done by the browser, not by MemoryLane.

If the browser has no speech recognition, the microphone button isn't shown.
