# Features

## Browser Extension

The Chrome extension automatically captures webpage information during browsing.

---

## Content Extraction

Webpage content is cleaned and processed to remove unnecessary information.

---

## AI Summarization

AI models generate summaries of stored webpages.

---

## Semantic Search

Users can search memories using natural language queries.

Example:

"Find documentation about ROS navigation"

---

## Memory Dashboard

The web application provides:

- Search interface
- Browsing timeline
- Stored memories
- Categories and tags

---

## User Authentication

Users can securely manage their personal browsing memories.
